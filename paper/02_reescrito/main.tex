% Los identificadores de modelo largos (p.ej. OLMo-2-0425-1B-Instruct) en
% \texttt{} dentro de prosa justificada producen Overfull \hbox puntuales;
% \emergencystretch le da a LaTeX margen para estirar espacios en vez de
% desbordar el margen en esos casos, sin alterar el resto del documento.
\emergencystretch=3em

% Presupuesto de páginas: el CFP de CACIC pide 10 páginas para trabajos
% completos (referencias incluidas, supuesto conservador). Con las tablas del
% cuerpo, el prompt íntegro y una figura, la separación por omisión de los
% flotantes fragmentaba el cuerpo; estos valores la ajustan sin tocar el
% interlineado del texto ni el cuerpo de letra de las tablas.
% El componente \plus (cuánto puede estirarse esta separación) sube de 2pt a
% 8pt tras la fusión de tablas (Tarea 5): la página que comparte la Tabla 2
% fusionada con fig1 dejaba un Underfull \vbox porque la separación fija no
% tenía margen para absorber la diferencia de alto; el valor base (8pt) no
% cambia, sólo cuánto puede estirarse cuando la página lo necesita.
\setlength{\textfloatsep}{8pt plus 8pt minus 2pt}
\setlength{\intextsep}{8pt plus 8pt minus 2pt}
\setlength{\floatsep}{8pt plus 8pt minus 2pt}
% llncs.cls deja \belowcaptionskip en 10pt (heredado de article.cls); bajarlo
% a 4pt ahorra ~3 líneas acumuladas sobre los captions de las tablas y la
% figura del documento, sin tocar el cuerpo de letra ni el interlineado.
\setlength{\belowcaptionskip}{4pt}
% Menos páginas rotas a la mitad por un flotante que no entra.
\renewcommand{\topfraction}{0.9}
\renewcommand{\bottomfraction}{0.7}
\renewcommand{\textfraction}{0.08}
% floatpagefraction sube de 0.8 a 0.92 (2026-08-05, tercera pasada): medido
% con \sbox, la Tabla 2 (222pt) y fig1 (216pt) miden 438pt de contenido
% puro sobre \textheight=549pt (79.9%); con la separación entre flotantes y
% hacia el texto que sigue (\floatsep + \textfloatsep, ~8-16pt cada una)
% quedan por encima del 0.8 anterior, así que LaTeX las trataba como
% "página de flotantes" dedicada -- sin una sola línea de prosa -- en vez
% de ponerlas juntas al tope de una página normal con texto debajo (que sí
% entra: 0.9 de \topfraction ya lo permitía). Subir el umbral a 0.92 hace
% que valga más la pena intercalar texto que dedicarles una página entera.
\renewcommand{\floatpagefraction}{0.92}
% Las referencias van sin aire extra entre entradas: es espacio en blanco, no
% contenido, y cuenta contra el limite de paginas. (llncs.cls ya fija \small
% en \thebibliography por su cuenta; no hace falta repetirlo aqui.)

\renewcommand{\thebibliography}[1]{%
  \viejathebibliography{#1}%
  \setlength{\itemsep}{0pt}%
  \setlength{\parsep}{0pt}%
  \setlength{\parskip}{0pt}%
}
